# MTProto Proxy Docker Stack

Проект собирает актуальный прокси из [официального репозитория Telegram](https://github.com/TelegramMessenger/MTProxy)

## Особенности
- 🔄 **Автообновление через Cron**: Автоматическое добавление задачи в `cron` для пересборки контейнера и подтягивания актуальных `proxy-secret` / `proxy-multi.conf` от серверов Telegram каждую ночь (в 04:00).
- ⚙️ **Автогенерация ключей**: При первом запуске скрипт сам создаст файл `.env` с криптографически стабильными 16-байтными `SECRET`.

## Требования
- Процессор x86
- Возможность запускать shell скрипты
- Docker


## Установка и запуск

1. Склонируйте или загрузите этот репозиторий на ваш сервер.
```bash
git clone https://github.com/RomGurd/mtproto.git
cd mtproto
```
2. Запустите скрипт инициализации

```bash
chmod +x init_and_add_to_cron.sh
./init_and_add_to_cron.sh
```
3. Зарегистрируйте свой прокси в @MTProxyBot и получите TAG
4. Обновите TAG в .env файле
5. Перезапустите контейнер

```bash
./start_command.sh
```

> info: Если обновление по cron не требуется можно сразу запускать `./start_command.sh` но потребуется создать `.env` самостоятельно

### Что делает скрипт установки?
1. Создает файл `.env` со случайными ключами `SECRET`(если файла еще нет).
2. Запускает `start_command.sh`, который удаляет старый контейнер, собирает свежий Docker-образ `mtproto:latest`, запускает его под именем `mtproxy` и очищает оставшийся кэш сборки Docker (dangling images). 
3. Добавляет в `cron` пользователя задачу на ежедневный перезапуск контейнера каждую ночь (`0 4 * * *`).

## Конфигурация (`.env`)

Конфигурационный файл `.env` генерируется автоматически при первом запуске. Вы можете отредактировать его для изменения портов или параметров (изменения вступят в силу после перезапуска через `./start_command.sh`):

* `USERNAME=nobody` — пользователь внутри контейнера.
* `PORT_LISTEN=8888` — внутренний порт.
* `PORT=443` — внешний порт, по спецификации рекомендуется 443 для обхода блокировок.
* `SECRET` — секрет для подключения клиентов (генерируется).
* `TAG` — ваш тег рекламного канала Telegram (генерируется).
* `WORKERCOUNT=0` — количество рабочих процессов (если у вас мощный сервер, можно увеличить значение).

## Ручной перезапуск

Если вам нужно вручную обновить прокси или применить новые настройки из `.env`, просто выполните:
```bash
./start_command.sh
```

## Управление логами Cron

Логи ежедневного обновления от `cron` пишутся в файл `cron.log` в корне проекта. Вы всегда можете проверить, успешно ли обновился ваш прокси-сервер ночью.
